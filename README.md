# Talker

**Talker** — это масштабируемый мессенджер на основе микросервисной архитектуры. Проект представляет собой монорепозиторий с микросервисами и сервер-шлюзом.

## Архитектура

| Сервис | Назначение | API / Порт |
| :--- | :--- | :--- |
| **Server Gateway** | Единая точка входа для клиентов (REST API), маршрутизация запросов к внутренним gRPC-сервисам. | REST (Gin) - `8080` |
| **User Service** | Управление пользователями, аутентификация (JWT), авторизация и управление правами доступа. | gRPC - `50051` |
| **Chat Service** | Управление чатами (создание, удаление, добавление/исключение участников). | gRPC - `50053` |
| **Message Service** | Отправка, получение, хранение и управление сообщениями. | gRPC - `50052` |
| **Poll Service** | Создание и управление опросами внутри чатов. | gRPC - в разработке |
| **Notification Service** | Отправка уведомлений пользователям о событиях. | gRPC - в разработке |

## Быстрый старт

### Через Docker
1.  **Клонируйте репозиторий:**
    ```bash
    $ git clone https://github.com/north-fy/talker.git
    $ cd talker
    ```
2. **Запускайте каждый сервис по отдельности**
   ```bash
    $ cd ./services/chat
    $ make docker-up
   ```

### Через k8s
1.  **Создайте отдельный namespace**
    ```bash
    $ kubectl create namespace 'name'
    ```
2.  **Запускайте каждый деплоймент по отдельности**
    ```bash
    $ cd ./deployment/chat
    $ kubectl apply -f .
    ```
